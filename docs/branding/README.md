# CraftGPT logo

The CraftGPT logo is a friendly robot face built into a grass and dirt block.

- [SVG logo](craftgpt-logo.svg): scalable artwork on a transparent background.
- [PNG logo](craftgpt-logo.png): 512 x 512 export for sites that require a raster image.

Keep the original proportions and the clear space around the block. Both files use the same artwork. The SVG uses vector shapes, with no fonts, scripts, external resources or embedded images.

This is original AI-assisted vector artwork with custom pixel textures. It contains no extracted Minecraft textures or OpenAI logo. The artwork is covered by this repository's MIT license.
